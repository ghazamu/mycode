## Multi-session Claude SDLC

`docs/sdlc/` holds the design for a team of Claude Code sessions (Lead, three dev lanes, QA and Ops)
that coordinate through **DevBus**, a Claude Code mod in `tools/devbus/`. To install it in a terminal session:

```
/plugin install devbus --marketplace ghazamu/mycode
```

Sessions that clone this repository enable it automatically through `.claude/settings.json`.
